## Official App

## Access Controls

Wishlist follows updates but grants no playable entitlement. Request Access applies for a chance to enter the August 21-23, 2026 Closed Beta. A pre-order guarantees entry to that beta under the published terms and also purchases the release product. These controls have distinct outcomes; do not assume a wishlist or request is a confirmed invitation.

The Steam library is where a successful entitlement and install option should appear. Old FirstLook registration and a Discord role are not required replacements for the current Steam beta route.

## Languages

The checked Steam listing provides interface support for 14 languages: English, French, Italian, German, Spanish from Spain, Japanese, Korean, Brazilian Portuguese, Russian, Simplified Chinese, Traditional Chinese, Polish, Turkish, and Ukrainian. English is the listed full-audio language.

Interface support does not imply full audio or subtitles in every language. Review the language table on Steam if a particular localization is essential, because support can be refined during Early Access.

## Requirements

WARDOGS requires a 64-bit Windows environment, broadband internet for online play, and the processor, memory, and graphics hardware stated on Steam. The checked storage figure is **50 GB available space**. That number is a capacity requirement, not a promise that the compressed network download will be exactly 50 GB. Updates, shader caches, and temporary installation work can require additional headroom.

Hardware requirements and target performance can change as the build is optimized. Use the current store table for component-level decisions instead of relying on one creator's Alpha performance.

## Anti-Cheat

The listing identifies Easy Anti-Cheat. Keep Windows, graphics drivers, Steam, and the anti-cheat service in a supported state. Security software or modified system components can interfere with initialization, but players should use official Steam verification and support routes rather than downloading replacement anti-cheat files from third parties.
