## Quick Answer

Infantry Mode is the new high-intent WARDOGS search because Update 0.1.2 placed it directly in Deploy alongside Official, Community and Low-Level servers. Treat it as a server ruleset to verify at match start, not as a promise that every heavy platform, FOB tool or indirect-fire system is absent. The safest squad plan is infantry-first: cheap repeatable kits, clear tower routes, short revives, map callouts and enough logistics discipline to replace losses.

The mode does not remove the need for planning. It makes planning more important because fights compress around Control Zone entrances, tower interiors, ridges and revive windows. Open the [interactive map](/en/tools/map), agree on approach lanes, then keep the [artillery calculator](/en/tools/artillery-calculator) ready for any server where L81 mortar or SPH-2 support still appears.

## Confirmed Facts

- Update 0.1.2 added Infantry Mode as a Deploy choice alongside Official, Community and Low-Level servers.
- The October 2 IR/CWIS hotfix stopped new IR Rangefinder vendor purchases until Season 02 and moved the CWIS-versus-Havoc timing back toward roughly six seconds.
- The official notes do not publish a complete Infantry Mode restriction list, so every squad should check the live server rules, vendor access, vehicle terminals and build prompts after joining.
- Map routes, tower roles, fallback lanes and range calls still matter because the three-team Control Zone loop keeps creating third-party pressure.
- The map and artillery calculator are planning tools; the live server rules and in-match build remain authoritative.

## What changed in Update 0.1.2

The official Update 0.1.2 note changed Deploy into a clearer server choice. Players can choose Official, Community, Infantry Mode or Low-Level, with restored Official filters and improved connection feedback. That means the search problem is no longer “does Infantry Mode exist?” The useful answer is what to check once the server loads.

Before spending cash, verify the server label, rules text, team size, available vendors, vehicle spawns and build prompts. If the match hides a vehicle terminal but still allows equipment purchases, the correct loadout is different from a server that disables most support systems. If the server still allows FOB work, Support players become even more valuable because infantry needs short reinforcement paths.

## What still matters on an infantry-first server

Infantry Mode rewards the basics that ordinary combined-arms chaos can hide: spacing, cover discipline, local voice, revives, ammunition sharing and clean target calls. Do not stack five players in one doorway because a tank is absent. Grenades, crossfires, third-team pressure and rooftop angles still punish predictable movement.

The best opening plan is a cheap kit that can be replaced without breaking the account balance. Bring a primary you can control, enough ammunition for two fights, a healing or support role if the squad lacks one, and only the specialist tools you know the server permits. If you are testing a new weapon or attachment, do it after the route is safe rather than during the first tower breach.

## Map route and tower plan

Use map planning before the squad sprints. Pick one main lane, one fallback lane and one rally point outside the loudest fight. On a three-team battlefield, the third faction often arrives after the first two teams reveal themselves. That makes a quiet side road useful only if it has cover, a revive point and a way out.

At the tower, separate jobs. One player watches stairs or roof access, one watches the road or ridge, one handles the terminal prompt, and one keeps revives safe. If the tower is under repeated explosives or mortar pressure, leave the room, reset outside the blast pattern and re-enter after the enemy reloads or moves.

## Mortar, CIWS and helicopter checks

Infantry Mode is not a license to ignore support changes. The October 2 IR/CWIS hotfix disabled new IR Rangefinder vendor purchases until Season 02 and moved the announced CWIS-versus-Havoc time back toward about six seconds. That affects Recon planning, helicopter risk and anti-air placement on any server where those systems remain relevant.

If L81 mortar is available, use one ranging round instead of guessing. Call target type, range, azimuth, first impact and correction. If mortars are unavailable, the same communication discipline still helps grenade, rocket and flank calls. If helicopters remain enabled, infantry should treat rotor sound as a timing signal: spread before landing zones, cover likely dismount paths and do not chase the aircraft while losing the objective.

## Loadout priorities

| Role need | Bring first | Avoid first |
| --- | --- | --- |
| Assault entry | controllable rifle, spare magazines, smoke or utility if available | expensive novelty weapon with untested recoil |
| Medic / revive | cover discipline, voice callouts, medical supplies | reviving in the same impact pattern repeatedly |
| Support / FOB | build tool, supply awareness, route marker | building where trucks or helicopters cannot resupply |
| Recon / spotting | clear marks, range and approach calls | assuming an IR Rangefinder can still be bought after the hotfix |
