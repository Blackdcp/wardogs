### Which Deploy choice should I use, and how do I join?

**Official** and **Community** distinguish server lists. **Infantry Mode** and **Low-Level** highlight community servers running those modifiers. Infantry Mode is the route for an infantry-focused match; Low-Level is the route for servers aimed at lower-level players. These labels do not establish an exact level cap, vehicle restriction list or different cash/XP rules: read the individual listing before committing your loadout.

1. Open **Deploy**, then select the list or modifier you want.
2. Select your region and check the server's full name, mode, rules and population. Hover to read a long name; Official has advanced filters again.
3. Choose a suitable entry and press **Join**. Update 0.1.2 shows the connecting state, followed by your queue position when a queue exists.
4. If nothing appears, clear relevant search filters and check empty/full visibility, then refresh. Compare [service notices](/en/guides/wardogs-server-status) before diagnosing an outage.

The [official 0.1.2 record](https://steamcommunity.com/app/1867240/discussions/0/585061535402989202/) confirms this navigation and gamepad support on the Deploy selection screen. It does not certify every subsequent menu or every server's admission rules.

## Quick Answer

You cannot currently download a WARDOGS dedicated-server package and run it on any VPS or home machine. Use the official announcement to reach QONZER, BisectHosting or xREALM, and ignore unrelated websites selling “reserved WARDOGS slots.”

Community hosting is still real. It is simply controlled at launch so the team can validate performance and security while protecting progression and economy systems from untrusted server changes.

## Confirmed Facts

The developer community-server update confirms four practical points:

- Three hosting companies have been approved for launch.
- Server code will not be released for arbitrary self-hosting at launch.
- Approved community servers can choose maps and modes on day one.
- Update 0.1.2 documents RCON security controls; a complete separate tool is not verified here.

The providers have been tested for performance and security. This helps keep server behavior closer to the supported build, but it does not mean every region, slot count, price, queue feature, or moderation command is already public.

## Why Self-Hosting Is Restricted

WARDOGS combines large matches, vehicles, construction, account progression, and a persistent economy. A freely modified server can affect more than map rotation: it could change rewards, unlock speed, item availability, or the reliability of account data. The developer says broader controls must therefore be considered against the economy.

That launch restriction does not prove self-hosting will never exist. It means no public server binary or container is promised for September 10. Treat future Linux binaries, SteamCMD instructions, mod frameworks, and provider APIs as unknown until an official technical page publishes them.

## Approved Hosting Providers

The official September 8 announcement names QONZER, BisectHosting and xREALM; verify current order links through official channels. A provider using the WARDOGS logo, accepting deposits, or listing a speculative product page is not automatically approved.

Before paying, verify:

1. The provider is linked by WARDOGS, BULKHEAD, Team17, or an official Steam announcement.
2. The selected region, slot count, billing period, cancellation rule, and DDoS protection are visible.
3. The product specifically supports the live WARDOGS build rather than a generic “coming soon” template.
4. Admin credentials are delivered through the provider panel, not a Discord direct message.
5. The order does not promise unsupported XP multipliers, economy editing, mods, or private server files.

Do not preorder an unofficial server merely to secure a name. The developer explicitly warned players to avoid unofficial server preorders.

## RCON and Administration

RCON remotely administers a running server. [Update 0.1.2](https://store.steampowered.com/news/app/1867240/view/712287592723252267) adds AllowedHosts restrictions, caps message/broadcast lengths, defaults responses to Standard rather than Full, and removes server internals from config responses. These are shipped controls; a complete command reference, authentication model, audit log and separate web panel are not established by that note.

A responsible launch checklist should prepare administrator roles, password storage, escalation rules, ban evidence, and a contact route before assuming commands exist. Do not publish copied RCON commands from another game; even familiar command names can behave differently.

When the tool launches, test read-only status and player-list actions before using disruptive commands. Keep owner credentials separate from moderator credentials if the system supports permission levels.

## Day-One Map and Mode Controls

Approved community servers can choose maps and modes at launch. The update does not promise custom maps, altered player counts, modded vehicles, unrestricted economy values, or arbitrary scripts. “Choose maps and modes” should be read literally until a provider panel or official manual shows more.

For a stable first weekend:

- Start with an official map and mode combination supported by the live build.
- Use the recommended player count and region before experimenting with capacity.
- Publish the server language, moderation rule, restart window, and expected play style.
- Keep economy and progression settings at supported defaults.
- Record crashes, queue failures, and performance problems with timestamps and build numbers.

## Economy and Progression Boundaries

The developer plans to add more controls over time where the persistent economy allows them. This wording matters. A community server may offer custom rotation or moderation without being allowed to grant unlimited cash, instant role XP, permanent unlocks, or transferable rewards.

Until server-specific rules are published, assume that progression-impacting options are restricted. Our [progression and wipes guide](/en/guides/wardogs-progression-wipes-guide) separates BULKHEAD's stated seasonal cash/XP policy from still-unknown Season 02 transition details, while the [money guide](/en/guides/wardogs-money-guide) keeps Beta values separate from live economy facts.

## Player Safety and Fake Server Offers

Use the in-game browser, official provider links, and verified WARDOGS channels. A server operator never needs your Steam Guard code, browser cookie, Discord token, or payment-account password. Do not install a “community server launcher” supplied in a private message.

If a listing claims official status, save the URL and compare it with the WARDOGS announcement. Report impersonation to the platform and provider rather than testing suspicious credentials. The same rule applies to fake RCON panels that ask server owners to sign in through an unrelated domain.

## Confirmed vs Unknown

**Confirmed:** three approved launch hosts; no arbitrary self-hosted server code at launch; provider testing for performance and security; map and mode selection on day one; RCON security controls in Update 0.1.2; additional controls considered later.

**Unknown:** provider pricing and current order links, prices, regions, slot tiers, complete RCON command reference and any separate tool release, Linux or SteamCMD support, modding, custom maps, progression settings, and any later self-hosting roadmap.

## FAQ

**Can a clan reserve a server now?** Only after WARDOGS publishes the approved providers and official purchase route. An unrelated preorder page is not evidence of approval.

**Can owners change XP or cash?** No such launch control is confirmed. The developer specifically ties future options to protection of the persistent economy.

**Will private servers appear in the normal browser?** Discovery, password, queue, favorite, and visibility options have not been fully documented. Check the live server browser and provider manual.
