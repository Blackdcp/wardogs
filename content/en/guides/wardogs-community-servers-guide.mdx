## September 15 update: Patch 0.11 is live

WARDOGS Early Access is live and **Patch 0.11 shipped on September 14**. The browser now separates **Official** and **Community** lists, Community servers gained reliable filters and text search, and **server IDs now persist across matches and restarts**, so a community can publish one permanent identifier for direct joins. A **Show Empty/Full** control was added to the quick bar, the Host button points at the correct destination, and server names must now be **alphabetical with no more than one consecutive space**.

Community-server matches also award a **5% End of Match cash bonus for the week following the patch**. Treat the bonus as time-limited and confirm it in the client before planning an economy grind around it.

Favourites, tiered priority queues, Message of the Day, seeding AFK controls, team switching, and improved warmup activities are announced for later and are not part of Patch 0.11.

WARDOGS community servers use **two approved hosting providers**. The developer does not plan to distribute server code for arbitrary self-hosting. Approved servers can select maps and modes, an RCON administration tool is in development, and more controls may arrive where they do not undermine the persistent economy.

## Quick Answer

You cannot currently download a WARDOGS dedicated-server package and run it on any VPS or home machine. Wait for the official provider announcement, then order only through the linked approved flow. Ignore websites selling “reserved WARDOGS slots” before the developer names the companies.

Community hosting is still real. It is simply controlled at launch so the team can validate performance and security while protecting progression and economy systems from untrusted server changes.

## Confirmed Facts

The developer community-server update confirms four practical points:

- Two hosting companies have been approved for launch.
- Server code will not be released for arbitrary self-hosting at launch.
- Approved community servers can choose maps and modes on day one.
- A dedicated RCON tool is being developed for administration.
- Patch 0.11 shipped persistent Community server IDs, text search, and a separate Community browser.

Use a persistent server ID as the stable way back to the same community: the old behaviour wiped IDs on map change or restart, so a saved ID is now a reliable join route for a group. Expect the new IDs to be much longer; the developer cites security reasons.

The providers have been tested for performance and security. This helps keep server behavior closer to the supported build, but it does not mean every region, slot count, price, queue feature, or moderation command is already public.

## How to Use This Guide

Use the confirmed launch model to avoid fake preorder pages, then check the provider and administration sections when official ordering opens. Treat prices, regions, slot counts, RCON commands, mod support, and progression controls as unknown until first-party documentation names them.

## Why Self-Hosting Is Restricted

WARDOGS combines large matches, vehicles, construction, account progression, and a persistent economy. A freely modified server can affect more than map rotation: it could change rewards, unlock speed, item availability, or the reliability of account data. The developer says broader controls must therefore be considered against the economy.

That launch restriction does not prove self-hosting will never exist. It means no public server binary or container is promised for September 10. Treat future Linux binaries, SteamCMD instructions, mod frameworks, and provider APIs as unknown until an official technical page publishes them.

## Approved Hosting Providers

The announcement says there are two approved providers, but players should wait for the official names and order links. A provider using the WARDOGS logo, accepting deposits, or listing a speculative product page is not automatically approved.

Before paying, verify:

1. The provider is linked by WARDOGS, BULKHEAD, Team17, or an official Steam announcement.
2. The selected region, slot count, billing period, cancellation rule, and DDoS protection are visible.
3. The product specifically supports the live WARDOGS build rather than a generic “coming soon” template.
4. Admin credentials are delivered through the provider panel, not a Discord direct message.
5. The order does not promise unsupported XP multipliers, economy editing, mods, or private server files.

Do not preorder an unofficial server merely to secure a name. The developer explicitly warned players to avoid unofficial server preorders.

## RCON and Administration

RCON is a remote administration interface used to monitor and manage a running game server. WARDOGS says its own RCON tool is in development. That supports the expectation of remote moderation, but the exact command set, authentication model, audit log, web panel, console compatibility, and release date remain unknown.

A responsible launch checklist should prepare administrator roles, password storage, escalation rules, ban evidence, and a contact route before assuming commands exist. Do not publish copied RCON commands from another game; even familiar command names can behave differently.

When the tool launches, test read-only status and player-list actions before using disruptive commands. Keep owner credentials separate from moderator credentials if the system supports permission levels.

## Day-One Map and Mode Controls

Approved community servers can choose maps and modes at launch. The update does not promise custom maps, altered player counts, modded vehicles, unrestricted economy values, or arbitrary scripts. “Choose maps and modes” should be read literally until a provider panel or official manual shows more.

For a stable first weekend:

- Start with an official map and mode combination supported by the live build.
- Use the recommended player count and region before experimenting with capacity.
- Publish the server language, moderation rule, restart window, and expected play style.
- Keep economy and progression settings at supported defaults.
- Record crashes, queue failures, and performance problems with timestamps and build numbers.

## Joining the Same Server Every Time

Patch 0.11 made Community server IDs persist across map changes and restarts. Before the patch, an ID was wiped whenever the server rotated, so a saved shortcut could point at nothing.

Practical use: publish the server's persistent ID in your community channel rather than a screenshot of the browser row. The new IDs are much longer than the old ones for security reasons, so copy the whole string and verify it once by joining before sharing it widely.

If your group cannot find the server, check the **Community** tab first, then use text search, then confirm whether **Show Empty/Full** is hiding a full server. Only after that should you consider a client or network fault.

## Naming Rules After Patch 0.11

Server names must now be alphabetical and may not contain more than one consecutive space. Names that used spacing or symbols to force a position at the top of the list will need to change. If a rename fails, remove repeated spaces and special characters first, then retype the name rather than pasting it from an older source.

## Using the One-Week 5% Bonus

Community matches award an extra 5% End of Match cash for the week following Patch 0.11. That bonus is an incentive to play normally, not a licence to optimise the economy through exploits.

Grind in a legitimate community server if you want the bonus, and do not chase "cash server" listings that promise abnormal payouts. The same patch notes that introduced the bonus also introduced the enforcement policy below it.

## Server Owner Checklist

- Record the persistent server ID and confirm it survives a restart before advertising the server.
- Rename to comply with alphabetical ordering and the single-space rule.
- Publish language, moderation rules, restart window, and expected play style in the server description.
- Keep economy and progression settings at supported defaults.
- Assign owner and moderator credentials separately when the RCON tool arrives.
- Log crashes, queue failures, and performance problems with timestamps and build numbers.

## Economy and Progression Boundaries

The developer plans to add more controls over time where the persistent economy allows them. This wording matters. A community server may offer custom rotation or moderation without being allowed to grant unlimited cash, instant role XP, permanent unlocks, or transferable rewards.

Until the rules are published, assume that progression-impacting options are restricted. ## Player Safety and Fake Server Offers

Use the in-game browser, official provider links, and verified WARDOGS channels. A server operator never needs your Steam Guard code, browser cookie, Discord token, or payment-account password. Do not install a “community server launcher” supplied in a private message.

If a listing claims official status, save the URL and compare it with the WARDOGS announcement. Report impersonation to the platform and provider rather than testing suspicious credentials. The same rule applies to fake RCON panels that ask server owners to sign in through an unrelated domain.

## Confirmed vs Unknown

**Confirmed:** two approved launch hosts; no arbitrary self-hosted server code at launch; provider testing for performance and security; map and mode selection on day one; RCON in development; Patch 0.11 browser split, persistent IDs, text search, Show Empty/Full, alphabetical naming, and the one-week 5% cash bonus; additional controls considered later.

## FAQ

**Can a clan reserve a server now?** Only after WARDOGS publishes the approved providers and official purchase route. An unrelated preorder page is not evidence of approval.

**Will private servers appear in the normal browser?** Discovery, password, queue, favorite, and visibility options have not been fully documented. Check the live server browser and provider manual.
