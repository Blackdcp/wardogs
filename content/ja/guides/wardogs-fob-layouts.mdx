## WakeUpのソロ・デュオV2：閉じる前に再入場を確認

一人か二人で補給・操作・修理まで担当できる小型火力拠点向けです。味方が頻繁に出入りする増援FOBなら、通常の入口を残してください。[WakeUpの映像](https://www.youtube.com/watch?v=z7wMLQQtIIM)は射撃場での配置実演であり、現行の実戦耐久試験ではありません。

| 出発前に用意 | 確認して記録すること |
| --- | --- |
| 輸送車一台、建材一パレット、弾薬一パレット | 作者の初期積載です。選んだ車が受け付ける荷物と購入量を記録。自動字幕だけで車種は断定しません |
| FOB、ハンマー、使用する建築の権限 | Bremer壁、Hesco各種、間接火力シェルター、偵察塔、迫撃砲陣地、Talonのプレビューと必要資材を先に確認 |
| 建築と修理の予備 | 外殻前・火器前・完成後の資材数を記録。再入場口の復旧分を別に残す。動画の一パレットは全地形共通の費用ではありません |
| 射界と搬入方向 | 壁を置く前に[マップ](/ja/tools/map)で決める |

以下は動画の相対位置と時刻に沿った手順です。地形や重なりで置けない場合は未完成のプレビューを調整し、画像の寸法を固定座標として使わないでください。

## 弾薬の受渡しと残量不足時の帰路

小型拠点にも搬入動線が必要です。補給側を空け、弾薬の受取人を決め、荷下ろし後の資源増加を確認します。建材と弾薬の分岐は[FOB受渡し表](/ja/guides/wardogs-fob-guide)へ。地面のパレットだけでは補給完了ではありません。建設式弾薬箱と突撃梯子はプレイヤーの提案であり、この配置に必要な実装済みレシピではありません。

## クイック回答

FOBはタワーへの増援、迫撃砲下での分散、保護された物流拠点など目的で配置を選びます。スポーン、弾薬、修理、荷下ろしを分け、1発で全機能が停止しないようにします。

## 確認済み情報

ここで示す配置は戦術上の提案で、公式に保証された安全距離や建築上限ではありません。建築権限、費用、必要資源は現在の画面で確認します。Update 0.1.2は補給悪用への報酬も変更しています。

## 操作手順

1. **外周を仮置き：0:44–3:17。** FOBを予定するTalonの射撃方向と反対向きに置きます。最初のBremerをFOBの近くで少し左にはみ出す位置へ。次の壁はスナップ後に解除し、実演の半分ずらした位置に合わせ、各辺三枚を繰り返します。角と隙間を確認してから完成させます。
2. **中央の動線：3:37–4:59。** 延長する側に間接火力シェルターを置き、偵察塔の梯子を内側へ向けます。搬入側からシェルター、梯子までハンマーを持って歩ける間は作業口を塞がないでください。
3. **Hesco防護：5:05–7:16。** 塔とシェルター周囲を映像に合わせます。6:23のように作業マークが隙間に埋まらない側から施工。触れない場合は反対側へ回るか未完成部を動かし、上から壁を重ねないでください。
4. **火器側：7:27–9:57。** 迫撃砲陣地を外向きにし、上部のBremer/Hescoと迫撃砲側のドアを配置。Talonの完成時は横に立ちます。上に立つとブロックへ押し込まれる失敗が実演されています。
5. **閉鎖前の移動試験：10:08–14:35。** 側面の各くぼみに入り、よじ登って戻る、シェルターへ行く、階段と脱出口を通る操作を試します。Talon横のドアは退出用で、普段の確実な入口ではありません。二人なら一人を外に残します。
6. **射界確認：16:18。** 最後の土嚢を足す前にTalonの低角度の視界を確認。自分の防護が遮るなら向きや配置を変更します。遮蔽物は手榴弾・ロケット・砲撃への無敵保証ではありません。

次の再入場試験に合格するまで完全閉鎖しません。射撃場の施工速度と動画中の迫撃砲到達範囲を、実戦の工期や共通射程に換算しないでください。

## 実践例

**死亡後を想定した再入場試験：** 閉鎖前に、外からハンマーで届く間接火力シェルター上のHescoを特定します。作者はパラシュートで戻るか、この一個を撤去して入り、再建する方法を説明しています。安定してできなければ通常の作業口を残します。故意に死亡する必要はなく、味方を外に置くか、復旧可能な状態で一度歩いて出て戻ります。

| 試験記録 | 自分の観測を記入 |
| --- | --- |
| 開口 | 撤去した部材の種類・位置、撤去前の画像 |
| 復旧 | 取り外し・損傷したHesco全てと、開口で影響した迫撃砲陣地外周。実際に再建した数 |
| 費用 | 資材の前後差、補充で実際に払ったCash、火器を離れた時間 |
| 合格条件 | 入場、作業マークへの到達、開口の復旧、再退出ができるか |

修理予備を使い切る、直せない部材が残る、操作者が閉じ込められる場合は閉鎖をやめます。完成図と積載量は[FOBプランナー](/ja/tools/logistics-planner)に保存できますが、ゲーム内の配置判定を代行するものではありません。

## よくある失敗

味方の荷下ろし、修理、退避を塞ぐ壁は強化になりません。追加投資の前に新規スポーンの徒歩経路と補給車の進入を実際に確認します。敵が配置を覚えるため、攻撃を受けるたび見直します。
