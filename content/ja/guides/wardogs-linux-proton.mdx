## 使える互換性報告に必要な項目

**2026-10-09 再確認：**公式の立場は 2026-09-25 の声明のままで、対応する Proton バージョンや時期は未発表です。[Linux Support の議論](https://discord.com/channels/1464219389913071646/1551954554579451924/threads/1551967453574332556)には要望や個別の体験談がありますが、新しい公式対応の発表ではありません。今回、現行版の Linux・Steam Deck で成功例や失敗例を独自に再現したわけではありません。

| 段階 | 確認・記録すること | 結果から分かる範囲 |
| --- | --- | --- |
| ネイティブ Linux | 公式リリースにネイティブ版の提供が明記されているか確認。 | Windows 版が Proton で動いても、Linux ネイティブ対応にはなりません。 |
| Proton での起動 | 正確な Proton バージョンと起動オプションを記録。プロセス開始とメニュー表示を分け、終了時はエラーをそのまま保存。 | メニュー表示で確認できるのは、その環境での起動段階だけです。 |
| アンチチート・オンライン対戦 | [サーバー告知](/ja/guides/wardogs-server-status)を確認し、サーバー参加・試合完了・再接続を別々に記録。アンチチートと接続のエラーも分ける。 | 失敗だけでは Proton・アンチチート・サービス障害のどれが原因か断定できません。チェックを回避しないでください。 |

1. 日時、ゲームビルド、ディストリビューション/OS・カーネル、GPU・ドライバー、Proton バージョン、起動オプション、正確なエラー、最後に成功した段階を残します。関連ログを保存し、公開前にアカウント識別情報や個人のパスを取り除きます。
2. 設定は一つずつ変更し、同じ段階で再試験します。DLSS やアンチエイリアス変更で改善した個人の報告は、共通の Linux 修正方法ではありません。変更前後の設定と結果を残します。
3. ホットフィックス後は比較対象を同じ**新しいゲームビルド**にそろえ、旧ビルドの失敗記録も保存して、起動・参加・試合・再接続を再確認します。ベータの成功を製品版の結果として扱いません。
4. WD-L020 が出たら、OS とともに報告します。[既知の問題](/ja/guides/wardogs-known-issues)の Windows 更新手順は Linux 用ではありません。対応プラットフォームの問題と Windows の修復を分け、回避コマンドや実行ファイルの差し替えは案内しません。

## 結論

9月25日の開発者更新時点でも、WARDOGSは**Linuxを公式サポートしていません**。BULKHEADは公式Linux Proton互換性を開発中だと案内していますが、対応Proton版、対応時期、Steam Deckの状態は発表していません。Linuxで遊べることが購入条件なら、BULKHEADまたはSteamの公式更新で明確な発表が出るまで待つのが安全です。

[2026-09-25に追記されたSteamの固定投稿](https://steamcommunity.com/app/1867240/discussions/0/588436698284962639)でも、開発者は互換性について新たに共有できる情報や予定時期はないと明言しました。Proton対応は目標であり、公開日が発表されたわけではありません。

これは、特定のLinuxディストリビューション、PC、Steam Deckで絶対に起動しないという断定ではありません。プレイヤーの報告、ベータビルド、起動オプションはパッチで変わる可能性があり、公式の互換性保証にはなりません。このページでは、開発元が確認した範囲と個別のコミュニティ検証を分けています。

## 確認済み情報

- WARDOGSは現在SteamのWindows PC向けに発表されています。
- BULKHEADはLinuxをローンチ時に公式サポートしないと説明しています。
- 公式Linux Proton互換性は開発中です。
- ローンチ時の対応保証、対応Proton版、対応日付は公開されていません。
- Steam Deck VerifiedまたはPlayableの公式状態は公開されていません。
- プラットフォーム範囲が変わる場合はSteamとBULKHEADを確認してください。

Steamに掲載されたWindowsの要件は、Linuxの要件ではありません。同じドライバ、アンチチート経路、性能目標がProtonで使えることを証明するものではありません。確認済みのWindowsハードウェア要件は[WARDOGSシステム要件](/ja/guides/wardogs-system-requirements)で確認できます。

## ここから分からないこと

Proton対応の開発中という情報だけでは、どのProton版が対応対象か、すべてのLinuxディストリビューションで動くか、Steam Deckの性能目標があるか、Steamの互換性ラベルがいつ付くかは分かりません。ネイティブLinuxクライアントの存在も確認されていません。公式が具体的に示すまでは、これらは未確認です。

テストクライアントで動作したという報告は、製品版でも同じ結果になる証明ではありません。テスト用アプリ、サーバー設定、アンチチート統合、パッチ、ストア用ビルドは異なる場合があります。報告は開発元へのフィードバックには役立ちますが、他のプレイヤーへの購入保証にはなりません。

## 購入前の安全な判断

Windows PCで遊ぶ場合は、公式の要件と[WARDOGSダウンロードガイド](/ja/guides/wardogs-download)を使ってください。LinuxまたはSteam Deckだけで遊ぶ予定なら、SteamかBULKHEADが公式互換性を発表するまで待つのが安全です。

非公式ランチャーの導入、ゲームファイルの置き換え、アンチチートの回避、未対応マルチプレイヤークライアントを安全だとする手順には従わないでください。これらはセキュリティやアカウントのリスクになり、未対応環境を公式対応に変えるものではありません。Steamクライアントとゲームファイルは変更しないでください。

## 次に確認すること

意味のある更新には、少なくとも一つの具体的な情報が必要です。たとえば特定の段階での公式Linuxサポート、公式Proton対応目標、Steam Deckでの検証結果、Steam商品ページの明確な変更です。公式出所のないスクリーンショット、再投稿、配信者テストでは、この状態を変更できません。

Linux目的でインストールや購入をする前に、WARDOGSのSteamページと公式Steam Community更新を確認してください。ネイティブビルド、Proton互換性、限定テスト、ロードマップ発言は異なるサポート段階です。

## よくある質問

**WARDOGSは現在Linuxを公式サポートしていますか？**

いいえ。開発者による9月25日の更新では、Linux対応やProton互換性の予定時期は発表されていません。

**Protonで動くと考えてよいですか？**

いいえ。公式Proton互換性は開発中ですが、対応版、日付、ローンチ時の約束はありません。

**Steam Deck Verifiedですか？**

Steam Deckの公式状態、Playableラベル、性能目標は今回の確認時点で公開されていません。

**マルチプレイヤー用の回避方法を使えますか？**

公式対応とは扱わず、アンチチートやゲーム保護を回避しないでください。開発元の発表を待ちましょう。
