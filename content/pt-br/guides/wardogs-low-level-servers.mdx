## Resposta rápida

**Treat Low-Level servers as a safer starting queue, not a separate ruleset that guarantees easy fights. Use them to learn vendor flow, deployment, towers, FOB basics and squad voice before moving into broader official or community servers.**

Esta página funciona como uma página de captura atual: entrega uma resposta direta, aponta para a ferramenta certa e mantém valores incertos marcados até confirmação primária.

## Fatos confirmados

- Update 0.1.2 says the Deploy flow now highlights Infantry Mode and Low-Level community servers.
- The patch note does not publish a universal level cap, full ruleset or permanent population guarantee.
- Community reports show confusion around server category labels and filters.
- Infantry Mode and Low-Level are separate search intents and should not be explained as the same thing.

## Plano de ação

### Start with one role

Pick Medic, Support or a simple rifle kit and repeat the same loop until the vendor, map and respawn flow are clear.

### Check the server category

Low-Level, Infantry, Official and Community labels can imply different rule expectations. Read the browser row before joining.

### Use cheap kits

The goal is information, not a highlight reel. Low-cost rifles and medical utility teach more than one expensive vehicle loss.

### Leave when the match no longer teaches

If the lobby is empty, stacked or using unexpected rules, switch categories instead of assuming the game is dead.

### Graduate with a checklist

Move on once you can spawn, regroup, reach a tower, revive, resupply and extract from pressure without panic.
