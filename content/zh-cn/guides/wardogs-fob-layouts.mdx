## WakeUp 单双人 V2：先验证回入，再封闭基地

适用于一到两个人能够负责补给、操作和修复的紧凑火力 FOB。若目标是让大量队友反复进出的公共复活点，应保留常规入口。[WakeUp 的原视频](https://www.youtube.com/watch?v=z7wMLQQtIIM)是在靶场演示的布局参考，不是当前实战耐久测试。

| 出发前准备 | 必须确认或记录 |
| --- | --- |
| 一辆运输车、一板建材、一板弹药 | 这是作者演示的初始装载；记录实际车辆可装的货物与购买量，自动字幕不足以确认具体车型 |
| FOB、锤子及示范中的建筑权限 | 先看 Bremer 墙、各型 Hesco、间接火力掩体、侦察塔、迫击炮坑和 Talon 的预览与材料需求，再采购整套 |
| 建造与维修余量 | 记录外壳前、武器前、完工后的资源数；另留回场拆墙后的补建材料，不把视频的一板材料当通用总价 |
| 预定射界与补给方向 | 先在[地图](/zh-cn/tools/map)标记；从哪边运货要在放墙前确定 |

下面按视频时间点和相对位置复现。地形不平或预览变红时，调整尚未完成的结构，不能把截图比例当成通用坐标。

## 弹药交接与低库存返程

紧凑布局也要有能接货的路线。留出补给侧入口，明确谁接弹药，卸货后检查资源实际增加。弹药与建材如何分流见[FOB 交接清单](/zh-cn/guides/wardogs-fob-guide)；附近有托盘不等于补给成功。玩家讨论的可建弹药箱、突击梯属于建议，不是此布局所需的已实装配方。

## 直接回答

FOB布局先选任务：支援塔点、承受迫击炮时分散、或保护物流中转。把出生、弹药、维修、卸货通道分开，避免一发炮弹同时中断整座基地。

## 确认信息

这些是战术建议，不是官方保证的安全间距或建造上限。当前建造权限、成本和所需资源要在客户端确认。Update 0.1.2也调整了与补给滥用相关的奖励，因此不能按旧刷钱布局替代前线需求。

## 操作步骤

1. **定向并预览外圈，0:44–3:17。** FOB 朝向背离计划的 Talon 射击方向。第一段 Bremer 靠近 FOB 并略向左突出；后续墙先吸附，再取消吸附移到作者示范的半幅位置，每边重复三段。先检查角部和缝隙，再完成墙体；角落重叠时在预览阶段调整。
2. **建立中间通道，3:37–4:59。** 在选定延伸侧放间接火力掩体，再放梯子朝内的侦察塔。保留施工通道，拿着锤子从卸货侧走到掩体、梯子，确认每段可达后再封闭。
3. **补 Hesco 防护，5:05–7:16。** 跟随视频围绕塔与掩体布置。站到能看见锤击标记的一侧施工；6:23 展示了标记卡进块缝的失败。如果标记不可达，换侧或重摆未完成的块，不要再叠墙遮住它。
4. **安装火力侧，7:27–9:57。** 迫击炮坑朝外，上层放 Bremer/Hesco，并把门朝向迫击炮。完成 Talon 时站在旁边，视频中站在其上会有被挤进块内的风险。
5. **封口前逐条走通，10:08–14:35。** 每个侧袋都走入并爬出，检查掩体、楼梯和逃生门。Talon 旁的门用于退出，不是可靠的日常入口；双人时一人在外等候，另一人测试进出。
6. **检查实际射界，16:18。** 最后一层沙袋前先看 Talon 预定低角度射线，被自家掩体挡住就改防护或朝向。掩蔽不等于免疫手雷、火箭或炮击。

下面的回场流程没有走通，就不要完成封口。靶场施工速度和作者展示的迫击炮覆盖，不是实战工期或通用射程。

## 实际示例

**死亡后的回场演练：** 封闭前先从外面找到间接火力掩体上方、锤子能操作的那块 Hesco。作者描述的方案是跳伞回入，或拆掉此块进入后再补回。两条都无法稳定完成，就保留普通维修入口。无需故意送掉一条命测试：让队友留外侧，或在开口仍可恢复时自行走出再返回。

| 一次演练记录 | 填自己的实际观察 |
| --- | --- |
| 开口 | 被拆块的类型与位置；拆前截图 |
| 补建 | 所有拆除或损坏的 Hesco，含重新开口影响到的迫击炮坑外围；实际补回数量 |
| 成本 | 建材前后数、实际花钱补货额、离开武器的时间 |
| 验收 | 是否能进入、触达锤击标记、补回开口并再次离开 |

如果回场耗尽维修余量、留下一块不可修结构或把操作员困住，停止封闭并保留维修入口。把完工布局与装货数记进[FOB 规划器](/zh-cn/tools/logistics-planner)，规划器不会替你验证游戏内放置。

## 常见错误

挡住己方卸货、修理或撤退的墙并不是升级。追加设施之前，以刚出生的步兵走一次路线，再开补给车测试入口。每次受袭后重新检查，因为敌人已经掌握布局，静态照搬不保证安全。
