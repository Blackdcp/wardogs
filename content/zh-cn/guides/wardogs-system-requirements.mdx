## WARDOGS 配置要求是什么？

官方最低配置从 **Windows 10 64 位、Core i5-8600 或 Ryzen 5 3500、16 GB RAM、GTX 1660 或 RX 590、50 GB 可用空间**起步。官方最低性能目标是 1080p 低画质、使用升频达到 60fps；这不是原生 1080p 或所有战况下锁定 60fps 的保证。

## 快速结论

如果电脑只刚好达到最低配置，应把目标放在低画质、升频和稳定帧时间，而不是最高画质。推荐配置面向中画质：1440p 原生 70fps 以上，或 4K 使用升频达到 60fps 以上。大型 Control Zone 战斗中的玩家、载具、爆炸、建造和破坏会同时增加 CPU 与 GPU 压力，空服或训练场不能代表最重负载。

## Linux、Proton 与 Steam Deck

这里列出的都是 **Windows PC** 配置，不是 Linux 配置。BULKHEAD 表示 WARDOGS 在首发时没有 Linux 官方支持，官方 Proton 兼容性仍在开发中；Steam Deck 状态也尚未公布。不要把 Windows 配置直接套到 Proton 上，购买前请先看 [WARDOGS Linux 与 Proton 支持状态](/zh-cn/guides/wardogs-linux-proton)。

## 已确认信息

- 当前已确认平台是 Windows PC Steam。
- 最低 CPU：Intel Core i5-8600 或 AMD Ryzen 5 3500。
- 最低 GPU：Nvidia GTX 1660 或 AMD Radeon RX 590。
- 推荐 CPU：Intel Core i7-12700K 或 AMD Ryzen 7 5700X。
- 推荐 GPU：Nvidia RTX 3070 或 AMD Radeon RX 6700 XT。
- 最低和推荐配置都列出 16 GB RAM、宽带网络和 50 GB 可用空间。
- 最低目标：1080p 低画质、升频、60fps。
- 推荐目标：1440p 中画质原生 70fps 以上，或 4K 中画质升频 60fps 以上。

## 玩家想知道什么

搜索 `wardogs system requirements` 的玩家需要的是整机判断，不是只比较显卡。CPU、内存、显卡、系统版本、存储空间和散热都可能成为限制。即使显卡达到最低要求，较弱 CPU 或后台占用也可能在百人战斗中造成卡顿和帧时间波动。

“50 GB”也经常被误解。Steam 写的是可用存储空间，不是承诺网络下载包恰好为 50 GB。安装解压、补丁、着色器缓存、录屏和 Windows 本身都需要额外余量。

## 如何使用本攻略

先在 Windows 设置和任务管理器中确认 CPU、GPU、内存、系统版本与磁盘空间，然后按完整的一档配置比较。不要把移动版显卡与同名桌面卡默认视为相同表现。若接近最低配置，先阅读画面设置攻略；若满足要求却无法启动，再检查驱动、Easy Anti-Cheat、文件完整性和后台冲突。

## 官方最低配置

| 部件 | 官方最低要求 |
| --- | --- |
| 操作系统 | Windows 10 64 位 |
| 处理器 | Intel Core i5-8600 或 AMD Ryzen 5 3500 |
| 内存 | 16 GB RAM |
| 显卡 | Nvidia GTX 1660 或 AMD Radeon RX 590 |
| 网络 | 宽带互联网连接 |
| 存储 | 50 GB 可用空间 |
| 性能目标 | 1080p 低画质，升频，60fps |

达到最低型号意味着官方认为该整机档位可瞄准上述条件，不代表原生分辨率、高画质或所有服务器都能稳定达到同样结果。驱动、温度、双通道内存、后台软件和预发布构建都会影响表现。

## 官方推荐配置

| 部件 | 官方推荐要求 |
| --- | --- |
| 操作系统 | Windows 11 64 位 |
| 处理器 | Intel Core i7-12700K 或 AMD Ryzen 7 5700X |
| 内存 | 16 GB RAM |
| 显卡 | Nvidia RTX 3070 或 AMD Radeon RX 6700 XT |
| 网络 | 宽带互联网连接 |
| 存储 | 50 GB 可用空间 |
| 性能目标 | 1440p 中画质原生 70fps+，或 4K 中画质升频 60fps+ |

推荐配置不是“最高画质配置”。官方目标仍写的是中画质。想要高刷新率、最高特效、超宽屏或更高原生分辨率的玩家，需要为 CPU、GPU 和散热保留更多余量，并在实际版本上线后重新测试。

## 怎么查看自己的电脑配置

打开 **设置 > 系统 > 系统信息**查看处理器、已安装内存和 Windows 版本；打开 **任务管理器 > 性能 > GPU**确认显卡型号；在文件资源管理器中查看 Steam 安装盘剩余空间。

笔记本还要确认游戏使用独立显卡，并在接通电源后选择合适的性能模式。同一型号的移动显卡会因功耗和散热设计出现明显差异，所以“型号相同”不等于持续性能相同。

## 实战性能怎么判断

进入游戏后，应该在玩家密集、载具和破坏效果较多的 Control Zone 测试，而不是只看菜单、出生点或空服的峰值帧率。记录平均帧率的同时关注最低帧和卡顿，单次最高数字没有太大意义。

如果降低分辨率后帧率明显上升，GPU 更可能是主要限制；如果分辨率降低帮助很小，但大规模战斗仍会掉帧，CPU、内存或当前构建可能更关键。一次只改一个设置，才能知道真正有效的是哪项。

网络延迟与本地渲染也要分开判断。画面帧率稳定时仍可能出现橡皮筋、位置回弹或服务器反馈延迟；反过来，低 FPS 也不一定是网络故障。官方商店页还标注 Easy Anti-Cheat，启动问题可能与反作弊服务、权限或安全软件有关。

## 常见问题

**8 GB 内存能玩吗？**
它低于官方最低要求。即使客户端能够启动，也不能据此认为达到受支持配置。

**GTX 1660 的目标是原生 1080p 吗？**
不是。Steam 写的是 1080p 低画质、使用升频达到 60fps。

**RTX 3070 能跑 4K 吗？**
官方推荐目标之一是 4K 中画质、升频、60fps 以上；实际结果仍取决于整机、驱动和当前版本。

**50 GB 空间刚好够吗？**
官方要求是 50 GB 可用空间，但为安装、更新和缓存预留更多空间更稳妥。

## 来源和最后检查

所有硬件型号、系统要求和性能目标均核对自 WARDOGS Steam 官方商店页，并与 BULKHEAD 官方产品页面交叉确认。最后核查日期为 **2026-09-01**。抢先体验期间优化和配置要求可能调整，购买硬件前应再次查看 Steam。
