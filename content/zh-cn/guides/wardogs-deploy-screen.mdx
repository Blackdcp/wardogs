## 快速答案

Deploy Screen 是服务器和模式的路由层，不是简单的开始按钮。你需要先判断 Official、Community、Infantry、Low-Level 和筛选条件，再决定要进哪一类对局。空列表通常先排查筛选和分类，而不是立刻重装游戏。

## 已确认事实

- Patch 0.11 已经把 Official 与 Community server browser 分开。
- Update 0.1.2 又调整了 Deploy 体验，并把 Infantry Mode、Low-Level servers 放进更明显的位置。
- 社区 bug 反馈显示，玩家会遇到空列表、筛选误导、分类混淆和好友加入 workaround。
- Deploy 问题和 WD-L020、WD-L018、反作弊、权限错误不是同一类问题。

## 行动方案

### 第一步清空筛选

先关闭可能限制结果的过滤项，包括地区、满服、空服、模式、社区类型等。很多“没有服务器”的情况，其实是筛选组合太窄。

### 分开检查 Official 和 Community

Official 没结果不等于 Community 也没结果，反过来也一样。Patch 0.11 以后这两个入口应该分开判断。

### 单独测试 Infantry 和 Low-Level

如果你是为了步兵局或低等级入口来玩，就不要只看默认列表。切到对应分类，确认列表、人数和规则是否符合预期。

### 和状态页交叉验证

如果所有分类都异常，再去看 server status、patch notes 和 known issues。只有多个入口同时失败，才更像服务端或版本问题。

### 报告要有可复现信息

有用的反馈包括时间、地区、分类、筛选条件、错误码、是否能跟好友加入，以及客户端版本。只说“Deploy 坏了”很难定位。
