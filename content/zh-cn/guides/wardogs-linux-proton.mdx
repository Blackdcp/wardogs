## 快速结论

WARDOGS 在**首发时不提供 Linux 官方支持**。BULKHEAD 表示正在开发官方 Linux Proton 兼容性，但没有承诺首发可用，也没有公布支持的 Proton 版本、支持日期或 Steam Deck 状态。若 Linux 是你购买游戏的必要条件，最稳妥的做法是等待 BULKHEAD 或官方 Steam 页面给出明确更新。

这不等于“某个 Linux 发行版、某台电脑或某台 Steam Deck 永远无法启动游戏”。玩家实测、测试版构建或某条启动参数都可能在补丁后改变，不能自动成为官方兼容性保证。本页只记录开发方已确认的范围，并把它与社区的个别体验分开。

## 已确认信息

- WARDOGS 当前公布的平台是 Steam 上的 Windows PC。
- BULKHEAD 表示 Linux 在首发时没有官方支持。
- 官方 Linux Proton 兼容性仍在开发中。
- 尚未公布首发支持承诺、支持的 Proton 版本或 Linux 支持日期。
- 尚未公布 Steam Deck Verified 或 Playable 状态。
- 平台范围发生变化时，应以 Steam 与 BULKHEAD 的官方信息为准。

Steam 页面上的 Windows 硬件配置只适用于 Windows 版本。它不能证明 Linux 下会使用相同的驱动、反作弊路径或性能目标。已确认的 Windows 硬件信息请看 [WARDOGS PC 配置要求](/zh-cn/guides/wardogs-system-requirements)。

## 这些信息没有确认什么

“正在开发 Proton 兼容性”并不说明会支持哪一版 Proton、所有 Linux 发行版是否都能运行、Steam Deck 是否有性能目标、Steam 兼容性标签何时出现，也不等于确认会提供原生 Linux 客户端。在官方公告给出具体细节前，这些都应视为未知。

某个测试客户端在 Linux 上运行过，也不能证明正式商店版本会有同样结果。测试应用、服务器配置、反作弊集成、补丁和商店构建都可能不同。玩家报告可以成为开发者的反馈，但不能作为其他玩家购买游戏的保证。

## 购买前的安全判断

如果你使用 Windows PC，请按官方配置要求和 [WARDOGS 下载攻略](/zh-cn/guides/wardogs-download) 安装。如果 Linux 或 Steam Deck 是唯一的目标设备，最安全的选择是等待 Steam 或 BULKHEAD 明确宣布官方兼容性。

不要下载非官方启动器、替换游戏文件、绕过反作弊，或遵循声称能让“不受支持的多人客户端安全运行”的教程。这类操作可能带来安全或账号风险，也不会把未支持的环境变成官方支持。保持 Steam 客户端和游戏文件完整，遇到真实问题时使用官方支持渠道。

## 接下来该关注什么

真正有意义的更新至少会说明一项具体内容：某个明确阶段的官方 Linux 支持、官方 Proton 兼容性目标、Steam Deck 的验证结果，或 Steam 商店页上的明确改动。没有官方来源的截图、转发或博主测试，不足以改变本页的状态。

在为 Linux 专门安装或购买前，请再次查看 WARDOGS Steam 页面和官方 Steam Community 更新。原生客户端、Proton 兼容、有限测试和路线图表态是不同层级的支持，不能混为一谈。

## 常见问题

**WARDOGS 首发时官方支持 Linux 吗？**

不支持。官方更新说明 Linux 在首发时没有官方支持，也没有承诺首发当天的兼容性。

**我能默认它会在 Proton 上运行吗？**

不能。官方 Proton 兼容性仍在开发中，但没有支持版本、日期或首发承诺。

**WARDOGS 已经 Steam Deck Verified 了吗？**

本次核对时，没有看到官方 Steam Deck 状态、Playable 标签或性能目标。

**多人模式能用社区绕过办法吗？**

不要把它当作官方支持，更不要绕过反作弊或修改游戏保护机制。等待开发方的明确说明。
