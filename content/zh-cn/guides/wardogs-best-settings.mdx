## Beta 02 性能复测

Beta 02 比空射击场更适合重新验证设置：接近满员的服务器会同时考验 CPU、GPU、网络、破坏效果、载具和资源加载。先用 Steam 公布的性能目标建立基线，然后在同一个高负载目标区一次只改一项，比较帧时间稳定性。Potato Mode 与 Overkill Mode 是官方提出的性能方向，但都不是适合所有电脑的万能竞技预设；某位博主的单机测试也不能保证另一台电脑得到相同结果。

## 快速结论

WARDOGS 的最佳设置不是“全部最低”，而是让最拥挤战斗中的**帧时间稳定、目标清楚、输入一致**。先按 Steam 官方配置选择接近自己硬件的一档，以原生显示器分辨率和合理升频为起点，再在真实 Control Zone 中逐项调整。

BULKHEAD 官方开发日志提到 **Potato Mode、Overkill Mode 和 60+ FPS** 的开发目标。这证明团队在覆盖低端与高端硬件，但不代表每台电脑、每个服务器和每次大规模交战都能达到固定帧率。

## 已确认信息

- 最低配置：Windows 10 64 位、i5-8600 或 Ryzen 5 3500、16 GB RAM、GTX 1660 或 RX 590、50 GB 可用空间。
- 最低性能目标：1080p 低画质、使用升频、60fps。
- 推荐配置：Windows 11 64 位、i7-12700K 或 Ryzen 7 5700X、16 GB RAM、RTX 3070 或 RX 6700 XT。
- 推荐性能目标：1440p 中画质原生 70fps+，或 4K 中画质升频 60fps+。
- Potato Mode 与 Overkill Mode 来自官方性能开发日志；具体菜单和结果仍属版本相关。

官方目标是测试基线，不是锁帧承诺。驱动、散热、内存通道、后台软件、服务器负载和当前构建都会影响结果。

## 玩家想知道什么

玩家通常在找三类答案：最低配置能否稳定游玩、怎样减少团战卡顿、怎样保持远距离目标可读。第一类要看完整整机，第二类要区分 CPU 和 GPU 限制，第三类不能只追求最低画质。

创作者录像可以展示某套硬件在某个预发布版本中的表现，但如果没有分辨率、驱动、录制方式、服务器人数和完整配置，就不能把一个帧率数字推广到所有玩家。

## 如何使用本攻略

先阅读 [PC 配置要求](/zh-cn/guides/wardogs-system-requirements)，记录当前 CPU、GPU、内存、系统、分辨率和驱动版本。进入游戏后选择同一服务器或相近场景，保持测试路线一致，并一次只改变一个设置组。

不要在菜单、出生点或空训练区得出结论。最有代表性的场景应包含大量玩家、载具、烟雾、爆炸、建筑与破坏。记录平均 FPS 只是辅助，真正影响操作的是最低帧、帧时间尖峰和输入延迟。

## 基线测试

1. 更新显卡驱动并重启 Windows。
2. 关闭非必要录屏、浏览器和覆盖层，但保留实际游玩需要的语音。
3. 使用全屏或游戏当前最稳定的显示模式。
4. 从显示器原生分辨率和官方对应画质档开始。
5. 在拥挤 Control Zone 运行固定路线至少数分钟。
6. 记录平均帧率、最低帧、明显卡顿点与 GPU 占用。
7. 一次只改一个选项组，再重复同一路线。

若修改后只在空场提升，却在大规模交战中没有改善，就不应把它记为有效方案。

## 竞争优先级

先降低阴影、体积效果、特效和高成本后处理，再判断是否需要调整升频或分辨率比例。纹理质量主要受显存影响，盲目降到最低可能损失清晰度，却不一定解决 CPU 限制。

动态模糊、景深和电影效果若影响跟枪，可以关闭；视野提高周边信息，但会让远处目标更小，也可能增加渲染负担。选择能稳定识别步兵、车辆、塔台和 HUD 标记的组合，不要只复制主播截图。

## Potato Mode 与 Overkill Mode

**Potato Mode** 是面向低端硬件的官方性能路径。若当前版本提供它，可把它作为排错起点，再逐步恢复纹理、视距和辨识度重要的选项。它不是“任何电脑都能稳定 60fps”的保证。

**Overkill Mode** 面向更强硬件与更高视觉质量。只有在拥挤战斗中仍保持稳定帧时间、显存和温度余量时才值得使用。截图漂亮不等于多人对战更合适。

官方提到的 **60+ FPS** 是开发目标，需要与 Steam 配置表中的分辨率、画质和升频条件一起理解，不能脱离条件写成全场景承诺。

## CPU、GPU 与网络诊断

降低分辨率后帧率明显上升，通常说明 GPU 压力更大；降低分辨率帮助很小，但人数和破坏增加时卡顿，则更可能与 CPU、内存或当前构建有关。温度过高、功耗限制和后台进程也会造成持续降频。

网络延迟和渲染卡顿不是一回事。画面流畅但人物回弹、命中反馈延迟，先检查网络与服务器；本地 FPS 下降、镜头不连贯，则先检查硬件占用和设置。不要因网络问题反复重装显卡驱动，也不要因低帧率盲目更换服务器。

## 常见问题

**GTX 1660 从哪里开始调？**
从官方最低目标的 1080p、低画质和升频开始，再在真实战斗中检查帧时间。

**RTX 3070 应直接开 Overkill Mode 吗？**
不建议默认开启。Steam 推荐目标仍是中画质，先确认最重负载下有余量。

**所有选项调低为什么仍卡？**
可能是 CPU、内存、温度、后台进程、服务器或当前构建限制。用分辨率对照测试区分原因。

**更新后需要重测吗？**
需要。性能模式、默认值、渲染器和服务器负载都可能改变。
