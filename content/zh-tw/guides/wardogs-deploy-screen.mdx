## 快速答案

Deploy Screen 是伺服器和模式的路由层，不是简单的開始按钮。你需要先判断 Official、Community、Infantry、Low-Level 和筛选条件，再决定要進哪一類對局。空列表通常先排查筛选和分類，而不是立刻重装游戏。

## 已確認事实

- Patch 0.11 已经把 Official 與 Community server browser 分開。
- Update 0.1.2 又调整了 Deploy 体验，并把 Infantry Mode、Low-Level servers 放進更明显的位置。
- 社區 bug 反馈显示，玩家會遇到空列表、筛选误导、分類混淆和好友加入 workaround。
- Deploy 问題和 WD-L020、WD-L018、反作弊、权限错误不是同一類问題。

## 行动方案

### 第一步清空筛选

先关闭可能限制结果的过滤项，包括地區、满服、空服、模式、社區類型等。很多“没有伺服器”的情况，其实是筛选组合太窄。

### 分開检查 Official 和 Community

Official 没结果不等于 Community 也没结果，反过来也一样。Patch 0.11 以後這两個入口應该分開判断。

### 单独测试 Infantry 和 Low-Level

如果你是為了步兵局或低等級入口来玩，就不要只看默认列表。切到對應分類，確認列表、人數和规则是否符合预期。

### 和状态頁交叉验证

如果所有分類都异常，再去看 server status、patch notes 和 known issues。只有多個入口同時失败，才更像服务端或版本问題。

### 报告要有可复现資訊

有用的反馈包括時间、地區、分類、筛选条件、错误码、是否能跟好友加入，以及客户端版本。只说“Deploy 坏了”很难定位。
