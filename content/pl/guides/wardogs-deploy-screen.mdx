## Szybka odpowiedź

**Read the Deploy screen as a routing layer. If no servers show, clear filters, check Official and Community separately, test Infantry and Low-Level categories, then compare with the official announcements before blaming your PC.**

Ta strona działa jako aktualna strona docelowa: daje bezpośrednią odpowiedź, prowadzi do właściwego narzędzia i oznacza niepewne wartości do czasu potwierdzenia w źródle.

## Potwierdzone fakty

- Patch 0.11 split Official and Community browsing; Update 0.1.2 changed the Deploy UX again.
- Update 0.1.2 explicitly calls out Infantry Mode and Low-Level community server visibility.
- Community bug reports after 0.1.2 mention empty server browser views and filter confusion.
- A server browser problem is different from WD-L020, WD-L018 or entitlement errors.

## Plan działania

### Reset filters first

Turn off restrictive filters before concluding that servers are offline.

### Check both browser families

Official and Community listings can differ. A result in one family does not prove the other is broken.

### Use category labels deliberately

Infantry Mode, Low-Level and normal servers can serve different players and expectations.

### Compare status evidence

If several categories are empty, check server-status and patch notes before changing your install.

### Report exact state

Useful reports include category, filters, region, time, error code and whether joining a friend worked.
