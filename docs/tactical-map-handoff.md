# WARDOGS 交互式战术地图开发与交接指南 (Codex Handoff)

本文档供其他设备上的 Codex 或后续开发者接手地图实现。2026-09-30 已更正早期交接中缺少证据的测距、点位和处理质量断言；代码功能、素材声明与游戏实测是不同的验收范围。

---

## 1. 任务背景与核心交付

- **目标**：在 `wardogswiki.com` 上直接提供可缩放、可拖动的真实游戏 2D 交互地图，替代原本的静态攻略文字与外部链接。
- **本地实现状态（不替代生产部署回执）**：
  - [x] **三张底图**：Bakurani、Ozeti、Zestafona 均有 2048×2048 的 `overview.webp` 与 `overview.png`。已核对可解码性和页面加载，不代表地标、塔台点位、北向或游戏坐标已经核准。
  - [x] **素材记录**：各图 `README.txt` 保存站长关于团队制作及本站使用许可的声明。脚本读取声明为本站控制的瓦片源并拼接；WebP 以 quality=92 重新编码，不能称为无损文件。该记录不等于本轮独立完成权利链或当前游戏版本核验。
  - [x] **2D 交互组件**：平移拖拽、滚轮与双指捏合缩放、地图切换、用户手动标点、来源检索、分享与全屏回退。不提供未经校准的游戏网格或自动塔台坐标。
  - [x] **图片标尺与用户校准**：默认仅显示图片像素距离；用户提供基准线、水平距离、误差、来源和游戏版本后，显示有条件的米制估算。不是本站游戏实测比例，不能直接用于弹道解算。
  - [x] **双入口接入**：
    - 攻略页直接集成：`src/app/[locale]/guides/wardogs-map`（自动内嵌交互地图）
    - 独立战术工具页：`src/app/[locale]/tools/map`（支持中/英/德/俄/葡/日 6 语 SEO 与全景访问）
  - **质量与测试**：按待发布提交重跑相关检查；不要沿用早期测试数量作为当前构建或上线证明。

## 3. 合并与分支说明 (Branching)

`feat/interactive-map` 是早期开发分支记录，不是当前待合入分支的保证。接手时先核对工作区、远端 `main`、提交差异与生产 `/api/revision`；保留已有内容更新，不按旧文档直接合并，也不预先宣称零冲突。

## 4. 后续迭代建议 (Next Steps)

1. **塔台与据点**：取得对应版本的实机定位记录与可复核地标后再加入坐标。现有检索条目不能被当作已定位 POI。
2. **地图校准**：核对实际图片裁切、投影、朝向、多个分布地标的游戏坐标与水平距离，并用独立点检验误差。官方宣传面积不能直接推导为本地图片的边长；旧文档的 16×16 km、1px = 7.8125m 没有充分依据，不得作为默认值。
3. **弹道**：取得版本匹配的武器/弹药、初速、有效重力、阻力、角度定义、高程及平台姿态和命中验证后，再决定可发布的计算范围。未知阻力不等于零阻力，现实装备参数也不等于游戏参数。
