# WARDOGS Beta Weekend Content Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Publish a source-controlled WARDOGS Closed Beta weekend content package with three new guides, four refreshed access/store guides, and stronger homepage/news discovery.

**Architecture:** Keep every article in the existing keyword manifest and four-locale MDX matrix so routes, sitemap entries, metadata, FAQ schema, and related links continue to be generated by the current loaders. Treat official Steam, WARDOGS, Team17, and Twitch documentation as facts; use community discussion only to identify questions, never as proof of volatile queue or balance claims.

**Tech Stack:** Next.js 16, TypeScript, next-intl, MDX, Vitest, Playwright.

**Spec:** Approved weekend package in the 2026-08-22 task conversation.

## Global Constraints

- Add `wardogs twitch drops`, `wardogs beginner guide`, and `wardogs fob guide` as unique search intents.
- Maintain complete English, German, Russian, and Brazilian Portuguese content matrices.
- Every new page must include 3-5 FAQ entries, `updatedAt: 2026-08-22`, approved sources, and at least 1,200 characters of localized body copy.
- Do not publish unverified queue counts, exact server incident claims, or stable weapon-meta claims.
- Preserve all unrelated untracked workspace files.
